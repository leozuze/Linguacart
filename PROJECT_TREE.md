## Java backend packages

```text
com.linguacart.api          REST controllers
com.linguacart.dto          Request and response objects
com.linguacart.product      Product records and normalisation
com.linguacart.glossary     Shona-English glossary service
com.linguacart.cache        LRU translation cache
com.linguacart.search       Inverted index, vector search, ranking
com.linguacart.protection   Protected-field validation
com.linguacart.client       Python model-service client
com.linguacart.config       Configuration
```

## Data folders

```text
research/data/catalogue/          Licensed or open product catalogue

research/data/queries/            Shona test queries
research/data/judgments/          Query-product relevance judgments
research/data/translation_pairs/  Optional English-Shona translation pairs
```
